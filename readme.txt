Automatically update publication and modification dates of selected WordPress posts for SEO.

== Description ==

Auto Update Posts allows you to automatically refresh dates of specific posts using built-in WP-Cron. No external dependencies, no telemetry, just simple date management.

Features:
* Select posts by ID
* Three update modes: both dates, publish only, modify only
* Real-time update mode
* List of recent posts for easy ID copying
* Fully autonomous via WP-Cron

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/auto-update-posts/`
2. Activate through Plugins menu
3. Configure at Settings → Auto Update Posts
