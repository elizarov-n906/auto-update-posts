## Автоматическое обновление дат записей для SEO

**Auto Update Posts** — легкий плагин для WordPress, который автоматически обновляет даты публикации и/или изменения выбранных записей. Идеально подходит для поддержания актуальности старого контента в поисковых системах.

## О плагине

Плагин позволяет указать список ID записей и настроить обновление их дат. Поддерживает как мгновенное обновление через интерфейс, так и фоновую работу через серверный Cron (без зависимости от ненадежного WP-Cron на сайтах без трафика).

### Возможности:
*   Выбор конкретных записей по ID (с подсказкой последних 10 записей).
*   Три режима обновления: обе даты / только публикация / только изменение.
*   Режим реального времени для мгновенного применения.
*   Эндпоинт для вызова через серверный `cron` (например, через `wget`).
*   Никакой телеметрии, внешних запросов или сложной логики.

## Установка

1. Скачайте ZIP-архив из раздела **Releases**.
2. Перейдите в админке: **Плагины → Добавить новый → Загрузить плагин**.
3. Выберите файл `auto-update-posts.zip` и нажмите **Установить**.
4. Активируйте плагин.
5. Настройте параметры в разделе **Настройки → Auto Update Posts**.

---

## Использование

1. Укажите ID записей через запятую (например: `123,456,789`).
2. Выберите тип обновления дат.
3. Включите опцию «Включить автообновление».
4. Сохраните настройки.

**Для серверного Cron:**  

Добавьте в планировщик вашего хостинга задачу, выполняющую запрос к сайту с нужной периодичностью:


wget -q -O - https://zaplata.ru/?action=auto_update_posts_cron >/dev/null 2>&1
